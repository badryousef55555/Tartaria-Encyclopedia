# موسوعة حضارة تارتاريا

مشروع موسوعي بحثي باللغة العربية لدراسة المصطلح التاريخي «تارتاريا» والمناطق والشعوب والكيانات والثقافات التي ارتبطت به في مصادر العصور المختلفة.

> **تنبيه منهجي:** لا يفترض المشروع أن «تارتاريا» كانت دولة موحدة أو كياناً سياسياً واحداً ممتداً عبر التاريخ. يُدرس المصطلح بحسب سياقه الزمني والجغرافي والمصدري، مع الفصل بين الوقائع الموثقة والفرضيات والروايات غير المثبتة.

## حالة المشروع

المشروع في مرحلة **بناء الفهارس وتنظيمها**. لا تُعد العناوين أو المسودات اعتماداً نهائياً إلا إذا وُسمت صراحة بأنها معتمدة.

- الأبواب 01–03: فهارس معتمدة وفق سجل العمل الأصلي.
- الباب 04: مقترحات عائلات 61–80؛ غير معتمدة حتى مراجعتها.
- الباب 05: مقترحات عائلات 81–83، مع استمرار العمل من العائلة 84؛ غير معتمدة.
- الأبواب اللاحقة: تُستكمل وفق عناوين الهيكل الأصلي، ولا تُخترع عناوين بديلة عند غياب المرجع.

## مبادئ التحرير

1. التمييز بين الاسم التاريخي والاسم الذاتي والتسمية الخارجية.
2. عدم إسقاط الحدود والهويات القومية الحديثة على العصور القديمة والوسيطة.
3. عدم تحويل التشابه اللغوي أو الثقافي أو الجيني إلى إثبات نسب أو هوية بمفرده.
4. توثيق الادعاءات بمصادر قابلة للتحقق، مع عرض الأدلة المعارضة والبدائل.
5. منع التكرار والتداخل بين الأبواب والعائلات والفصول.
6. إبقاء المسودات منفصلة بوضوح عن المواد المعتمدة.
7. عدم كتابة المتون الموسوعية أو إنتاج نسخ HTML النهائية قبل اكتمال مرحلة الفهرسة واعتمادها.

## البنية

- `docs/STATUS.md` — سجل حالة الفهرسة والاعتماد.
- `docs/METHODOLOGY.md` — المنهج العلمي والتحريري.
- `catalog/` — فهارس الأجزاء والأبواب والعائلات والفصول.
- `references/` — المراجع وقواعد توثيقها.
- `CHANGELOG.md` — سجل التغييرات المهمة.

## الاعتماد والمراجعة

كل إضافة جديدة تبدأ بوصفها **مسودة غير معتمدة**. لا يتغير وضعها إلى «معتمد» إلا بعد مراجعة صريحة. ويجب أن يتضمن سجل التغيير نطاق التعديل وتاريخه وحالته.

## اللغة

اللغة الأساسية للمشروع: العربية. تُحفظ الأسماء الأجنبية بلغتها الأصلية عند الحاجة، مع تعريب منضبط وتوضيح اختلاف transliterations عند وجوده.
