# منهجية موسوعة الأوفاق والطلاسم

## 1. طبيعة المشروع
موسوعة تاريخية نقدية مقارنة، تدرس الأوفاق والطلاسم وعلوم الحروف والرموز بوصفها ظواهر نصية وفكرية ومادية واجتماعية عبر أزمنة وثقافات متعددة. لا تفترض صحة القوى الخارقة المنسوبة إليها، ولا تختزلها مسبقاً في تفسير واحد.

## 2. طبقات المعرفة
يُوسم كل ادعاء بحسب طبيعته:
1. **موثق مادياً:** مخطوط أو قطعة أو نقش أو أثر يمكن وصفه وفحصه.
2. **موثق نصياً:** نص معروف في مصدر قابل للتعيين، مع التمييز بين تاريخ التأليف وتاريخ النسخة.
3. **منقول تراثياً:** رواية أو نسبة يوردها مصدر، دون أن يعني ذلك صحتها التاريخية.
4. **تفسير بحثي:** قراءة حديثة أو فرضية علمية تُنسب إلى صاحبها.
5. **ادعاء خارق:** دعوى تأثير أو نتيجة فوق طبيعية؛ تُعرض بوصفها اعتقاداً أو دعوى، لا حقيقة مثبتة.
6. **غير محسوم:** مسألة لا تكفي الأدلة الحالية للحكم فيها.

## 3. التوثيق والتحقيق
- إثبات بيانات الطبعة أو المخطوط أو الفهرس ورقم الحفظ والورقة متى توافرت.
- التفريق بين المؤلف المنسوب إليه النص، والناسخ، والمالك، وتاريخ النسخة.
- عدم اعتماد عنوان الغلاف أو نسبة متأخرة دليلاً كافياً على المؤلف.
- مقابلة النسخ والطبعات عند توفرها، وتسجيل اختلافات العناوين والمتون.
- عدم اختلاق إحالات أو أرقام صفحات أو بيانات مخطوطات.
- توثيق الصور والرسوم والأختام والمواد والأبعاد ومكان الحفظ عند دراسة القطع.

## 4. التحليل
- تحليل رياضي للأوفاق: الرتب، المجاميع، الخواص، طرق الإنشاء، والاستثناءات.
- تحليل لغوي ورمزي للحروف والأسماء والاختصارات والكتابات المشفرة.
- دراسة تاريخية لمسارات الانتقال والتأثير، مع تجنب افتراض الاقتباس لمجرد التشابه.
- دراسة مادية واجتماعية لوظائف التمائم والوثائق واستعمالاتها وسياقات تداولها.
- مقارنة الثقافات مع بيان الفروق وعدم صهر التقاليد المختلفة في نظام واحد.

## 5. حدود العرض
تُدرس الطقوس والمواد والعبارات بوصفها موضوعاً تاريخياً ونصياً. لا تتحول الموسوعة إلى دليل تطبيقي لإيذاء الأشخاص أو استغلالهم أو التلاعب بهم، ولا تقدم الادعاءات العلاجية أو المالية أو التنبؤية على أنها مضمونة.

## 6. بنية كل فصل
1. تمهيد وتعريف وحدود الموضوع.
2. المصطلحات والمفاهيم.
3. النشأة والتطور الزمني.
4. المصادر الأولية والشواهد المادية.
5. المدارس والأعلام والنصوص.
6. التحليل المقارن.
7. الخلافات والإشكالات والنقد.
8. خلاصة النتائج ودرجة الثقة.
9. قائمة المصادر والمراجع.

## 7. معيار الجودة
كل فصل موسوعي مستقل، متماسك، عميق، موثق، لا يكرر الفصول الأخرى إلا بقدر الإحالة. تُذكر الفجوات البحثية صراحةً، وتُراجع المعلومات قبل تحويل المسودة إلى نسخة معتمدة.
