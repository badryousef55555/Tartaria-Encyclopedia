# موسوعة الأوفاق والطلاسم وعلوم الحروف والرموز

مشروع موسوعي بحثي مستقل، يُنشأ على فرع Git منفصل، لدراسة الأوفاق والطلاسم وعلوم الحروف والرموز في سياقاتها التاريخية والثقافية والفكرية والمخطوطاتية.

## نطاق المشروع
- 14 عائلة موضوعية، في كل عائلة 9 فصول؛ المجموع المخطط 126 فصلاً.
- العربية لغة التحرير الأساسية، مع إثبات المصطلحات الأجنبية عند الحاجة.
- منهج مقارن، وتفصيل موسوعي، وتنفيذ متسلسل.
- فصل واضح بين الوصف التاريخي، والاعتقاد المنقول، والتحليل الرياضي/اللغوي، والادعاء الخارق غير المثبت.

## الحالة
هذا الفرع هو مساحة العمل المستقلة للموسوعة. اعتماد الهيكل لا يعني اعتماد كل فصل أو اكتمال تحقيقه. تبقى الفصول مسودات حتى اعتمادها صراحةً، ولا توصف نسبة نص أو مخطوط بأنها ثابتة دون دليل.

## البنية
- `indexes/`: الفهرس العام وفهارس العائلات.
- `volumes/`: نصوص الفصول.
- `docs/`: المنهجية والحالة والسجل.
- `html/`: النسخة المنشورة بصيغة HTML عند تجهيزها.
- `downloads/`: حزم التوزيع عند إنشائها والتحقق منها.
