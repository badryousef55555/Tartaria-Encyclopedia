# موسوعة حضارة المايا

مشروع مستقل وفق الهيكل المعتمد: 9 عائلات × 9 فصول. تُنشأ ملفات HTML محلية عبر `python build_html.py`. الحالة الحالية: ملفات تأسيسية قيد التأليف والتحقيق وليست فصولاً نهائية معتمدة.

البناء الآلي: GitHub Actions؛ يتم اختبار عدد صفحات HTML وسلامة أرشيف ZIP قبل نشر artifact.


## تحرير المحتوى البحثي
أُضيفت مسودات موسعة وموثقة للفصول 1–9 ضمن العائلة الأولى. تبقى جميعها مسودات غير معتمدة وتخضع للمراجعة العلمية والتحريرية.

تم إصلاح قالب التوليد لضمان تضمين النصوص البحثية في صفحات HTML.

إعادة بناء بعد تحديث القالب: النسخة التالية ستضم المحتوى الموسع للعائلة الأولى.

تم تحديث صفحة البداية لتوضيح الفرق بين الفصول البحثية الموسعة والفصول التي ما زالت هياكل أولية.


## تقدم التأليف — العائلة الثانية
أُضيفت مسودات بحثية موسعة للفصول 10–18: التحولات السياسية قبل الكلاسيكي، نشوء الممالك، الملكية المقدسة، السلالات، الحرب والتحالفات، تنافس تيكال وكالاكموول، الممالك الإقليمية، التحولات ما بعد الكلاسيكية، والغزو الإسباني والمقاومة. أُدرجت روابط إلى دراسات ومصادر أكاديمية ومؤسسية. جميعها مسودات غير معتمدة وتحتاج مراجعة علمية وتدقيقًا ببليوغرافيًا قبل الاعتماد.


## تقدم التأليف — العائلة الثالثة
