# موسوعة حضارة المايا

مشروع مستقل وفق الهيكل المعتمد: 9 عائلات × 9 فصول. تُنشأ ملفات HTML محلية عبر `python build_html.py`. الحالة الحالية: ملفات تأسيسية قيد التأليف والتحقيق وليست فصولاً نهائية معتمدة.

البناء الآلي: GitHub Actions؛ يتم اختبار عدد صفحات HTML وسلامة أرشيف ZIP قبل نشر artifact.


## تحرير المحتوى البحثي
أُضيفت مسودات موسعة وموثقة للفصول 1–9 ضمن العائلة الأولى. تبقى جميعها مسودات غير معتمدة وتخضع للمراجعة العلمية والتحريرية.

تم إصلاح قالب التوليد لضمان تضمين النصوص البحثية في صفحات HTML.
