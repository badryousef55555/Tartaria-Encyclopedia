# العائلة الأولى — المفهوم والنشأة والجذور التاريخية

**الحالة:** مسودة تأسيسية غير معتمدة  
**عدد الفصول:** 9  
**التنسيق المنتج:** HTML مستقل + فهرس HTML + ملف إرشادات داخل ZIP

## الفصول
1. آشور ونينوى: المفاهيم والتسميات والحدود الحضارية
2. جغرافية شمال بلاد الرافدين والبيئة الطبيعية
3. أقدم الاستيطان البشري في منطقة نينوى
4. نشأة مدينة آشور والجذور الأولى للدولة الآشورية
5. نينوى في عصور ما قبل التاريخ والعصور المبكرة
6. آشور في الألف الثالث قبل الميلاد
7. العلاقات الآشورية مع سومر وأكد وبابل
8. الهوية الآشورية وتكوين الشخصية الحضارية
9. التسلسل الزمني للعصور الآشورية ومصادر دراستها

## الضوابط العلمية
- عدم مساواة نينوى بآشور: نينوى مدينة، وآشور قد تعني المدينة أو الإله أو البلاد أو الدولة.
- الفصل بين الشاهد الأثري والنص الملكي والتفسير الحديث.
- عدم تحويل التسميات الفخارية/الأثرية إلى هويات إثنية أو سياسية.
- عرض التواريخ بصفتها تقريبية عندما تختلف أنظمة التأريخ.
- إظهار فجوات المعرفة، خصوصًا في طبقات ما قبل التاريخ والتاريخ المبكر.
- عدم تقديم الفصول على أنها محققة أو معتمدة قبل مراجعة المصادر والصفحات والتواريخ ثم موافقة المستخدم.
