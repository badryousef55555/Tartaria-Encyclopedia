# المنهج العلمي والتحريري

## 1. طبيعة المصطلح

يُدرس مصطلح «تارتاريا» تاريخياً بوصفه تسمية وردت في خرائط ونصوص ومصادر مختلفة، وتغير نطاق استعمالها ومعناها عبر الأزمنة. لا يُفترض مسبقاً أنها تشير إلى شعب واحد أو دولة واحدة أو حضارة متجانسة.

## 2. درجات الثبوت

تُصنف المادة البحثية عند تحريرها إلى:

- **موثق:** تؤيده مصادر أولية أو دراسات أكاديمية موثوقة ويمكن التحقق من سياقه.
- **مرجح:** تدعمه قرائن معتبرة مع بقاء مساحة للنقاش.
- **فرضية:** تفسير قابل للاختبار لكنه غير محسوم.
- **رواية غير مثبتة:** ادعاء لا تتوافر له أدلة كافية أو لا يمكن التحقق من مصدره.
- **مرفوض أو منقوض:** يتعارض مع أدلة أقوى أو ثبت خطأ أساسه.

لا تُستخدم هذه التصنيفات كأحكام مسبقة؛ بل تُسند لكل ادعاء على حدة مع بيان السبب.

## 3. التعامل مع المصادر

لكل مرجع يُسجل، متى أمكن:
- المؤلف والعنوان وسنة النشر.
- نوع المصدر: أولي، دراسة محكمة، كتاب أكاديمي، قاعدة بيانات، أو مادة عامة.
- الصفحات أو الفصول ذات الصلة.
- رابط ثابت أو DOI أو بيانات النشر.
- الادعاء الذي يسنده وحدود ما يمكن استنتاجه منه.

تُعطى الأولوية للمصادر الأولية المحققة والدراسات الأكاديمية المحكمة والمؤسسات البحثية المعروفة. ولا يكفي تكرار الادعاء في مواقع متعددة لإثباته.

## 4. الفصل بين أنواع الأدلة

يجب التمييز بين:
- الدليل الأثري والمادي.
- النصوص التاريخية وسياق مؤلفيها.
- الأدلة اللغوية والمقارنة التاريخية.
- الأدلة السكانية والوراثية.
- الخرائط والتسميات الجغرافية.
- الذاكرة الشفوية والروايات المتوارثة.

لا يحل نوع واحد من الأدلة محل الأنواع الأخرى، ولا يثبت التشابه وحده علاقة سببية أو نسباً مباشراً.

## 5. بناء الفهرس

تُبنى الموسوعة وفق التسلسل: جزء ← باب ← عائلة موضوعية ← فصل. ويجب أن:
1. يكون لكل عائلة نطاق واضح لا يكرر عائلة أخرى.
2. يعالج كل فصل سؤالاً محدداً.
3. توضع الموضوعات العابرة في موضع رئيسي واحد مع إحالات متقاطعة عند الحاجة.
4. يُراجع الترتيب الزمني والجغرافي والمفاهيمي.
5. يُسجل وضع كل عنصر: مقترح، قيد المراجعة، معتمد، أو مؤجل.

## 6. الاعتماد

لا تتحول المسودة إلى مادة معتمدة بمجرد نشرها في المستودع. يتطلب الاعتماد مراجعة النطاق والتكرار والمصادر والصياغة، ثم تسجيل قرار الاعتماد بوضوح.
