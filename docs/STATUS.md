استُخدم ترقيم العائلات 61–80 للباب الرابع و81–100 للباب الخامس باعتباره امتداداً تنظيمياً مقترحاً. يجب مطابقته مع الفهرس الأصلي قبل اعتباره ترقيمًا نهائيًا معتمداً.
